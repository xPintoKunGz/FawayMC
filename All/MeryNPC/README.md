# ✦ MeryNPC (Version 26.3) ✦

**MeryNPC** เป็นปลั๊กอิน Minecraft สไตล์โมเดิร์นที่รวมความสามารถของ **Citizens** และ **CommandNPC** เข้าด้วยกันอย่างสมบูรณ์แบบ รองรับเวอร์ชัน 1.20 - 1.21.3+ และเวอร์ชันล่าสุด ออกแบบโทนสี Cyber Neon Gradient (`#00F2FE` ➔ `#4FACFE`) พร้อมระบบ GUI ทันสมัยใช้งานง่าย

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **สร้าง NPC ได้หลากหลายรูปแบบ (Citizens-like)**
   - สร้าง NPC ได้ทุกจุด พิกัดแม่นยำ พร้อมระบบ Auto-Save
   - รองรับประเภท: `ARMOR_STAND` (สวมใส่ชุด อาวุธ และจัดท่าทางได้เต็มที่), `PLAYER`, `VILLAGER`, `IRON_GOLEM`, `ALLAY` ฯลฯ
   - ระบบ **Look-At-Player**: NPC จะหันหน้ามองผู้เล่นที่เดินเข้ามาใกล้แบบสมูท

2. **ใส่คำสั่งในตัวได้ทุกคำสั่ง (CommandNPC-like)**
   - ผูกคำสั่งได้หลายคำสั่งต่อ 1 NPC
   - รองรับประเภทคำสั่ง:
     - `CONSOLE` - รันคำสั่งระดับคอนโซล
     - `PLAYER` - ให้ผู้เล่นที่กดเป็นคนรันคำสั่ง
     - `OP` - รันคำสั่งด้วยสิทธิ์ OP ชั่วคราว (บายพาสสิทธิ์)
     - `SERVER` - ส่งผู้เล่นข้ามเซิร์ฟเวอร์ (BungeeCord / Velocity)
     - `MESSAGE` - ส่งข้อความแชทหาผู้เล่น
     - `ACTIONBAR` - ส่งข้อความบน Actionbar
     - `TITLE` - แสดง Title เต็มหน้าจอ
   - รองรับเงื่อนไขการคลิก: `RIGHT_CLICK`, `LEFT_CLICK`, `SHIFT_RIGHT_CLICK`, `SHIFT_LEFT_CLICK`, `ANY`
   - ระบบ **Cooldown** และ **Permission** เฉพาะแต่ละคำสั่ง
   - รองรับระบบเงิน **Vault Economy** (หักเงินเมื่อกดใช้)
   - Placeholders: `%player%`, `%uuid%`, `%npc_id%`, `%npc_name%`, `%world%`, `%x%`, `%y%`, `%z%`

3. **เขียน Hologram บนหัว NPC**
   - ข้อความลอยหลายบรรทัดบนหัว NPC คมชัด ไม่สั่นไหว (ใช้ TextDisplay บน 1.20+)
   - รองรับสีรุ้ง สี HEX (`&#00F2FE` หรือ `<#00F2FE>`), Color Codes (`&a`, `&b`, `&l`) และภาษาไทย

4. **เปลี่ยนสกินได้ (Player Skins)**
   - ดึงสกินแท้จาก Mojang API โดยอัตโนมัติแบบ Asynchronous ไม่ทำให้เซิร์ฟเวอร์กระตุก
   - สกินจะถูกแปลงเป็น Player Head แบบ HD นำไปสวมใส่ให้ NPC ทันที

5. **เปลี่ยนท่าทาง & ถือดาบ ถือโล่ ใส่ชุดเกราะ (Pose & Equipment)**
   - **ท่าทางสำเร็จรูป (Presets)**:
     - `GUARD`: ท่าตั้งการ์ดพร้อมรบ ถือดาบและยกโล่เตรียมสู้
     - `ATTACK`: ท่ายกดาบฟันเฉียงพุ่งเข้าหาศัตรู
     - `DEFEND`: ท่ายกโล่ขึ้นบังด้านหน้าเต็มตัว
     - `SALUTE`: ท่าวัดทยาหัตถ์ (ทำความเคารพ)
     - `POINTING`: ท่าชี้นิ้วบอกทาง
     - `CHEERING`: ท่าดีใจ/ไชโย ชูมือสองข้างขึ้นฟ้า
     - `ZOMBIE`: ท่ายื่นแขนไปข้างหน้าสไตล์ซอมบี้
     - `SITTING`: ท่านั่ง
     - `STANDING`: ท่ายืนตรงตามธรรมชาติ
   - **ระบบ Equipment**:
     - มือหลัก: ดาบ / อาวุธ (`MAIN_HAND`)
     - มือรอง: โล่ / ทอเทม (`OFF_HAND`)
     - ชุดเกราะ: หมวก, เสื้อ, กางเกง, รองเท้า
     - ปุ่มลัด **Quick Copy**: คัดลอกอาวุธ โล่ และชุดเกราะจากตัวผู้เล่นไปใส่ให้ NPC ในคลิกเดียว!

6. **ระบบ GUI จัดการสุดล้ำ (Modern GUI)**
   - เปิดเมนูด้วย `/npc gui` หรือ `/npc edit`
   - จัดการอุปกรณ์, ท่าทาง, คำสั่ง, สกิน และวาร์ป ได้ในเมนูเดียว

## 📜 คำสั่งทั้งหมด (Commands)

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/npc help` | แสดงคู่มือคำสั่งทั้งหมดพร้อมธีมสีโมเดิร์น |
| `/npc create <ชื่อ> [ประเภท]` | สร้าง NPC ในจุดที่คุณยืน (ค่าเริ่มต้น: `ARMOR_STAND`) |
| `/npc select [id]` | เลือก NPC เพื่อตั้งค่า (หรือเลือกตัวที่อยู่ใกล้สุด) |
| `/npc gui [id]` หรือ `/npc edit [id]` | เปิดเมนู GUI ปรับแต่ง NPC แบบครบวงจร |
| `/npc list` | ดูรายชื่อและพิกัดของ NPC ทั้งหมดในเซิร์ฟเวอร์ |
| `/npc remove [id]` | ลบ NPC |
| `/npc rename <ชื่อใหม่>` | เปลี่ยนชื่อของ NPC |
| `/npc skin <ชื่อผู้เล่น>` | เปลี่ยนสกิน NPC โดยดึงจาก Mojang |
| `/npc pose <preset>` | เปลี่ยนท่าทาง (`guard`, `attack`, `defend`, `salute` ฯลฯ) |
| `/npc equip <hand\|offhand\|helmet\|chestplate\|leggings\|boots\|copy\|clear>` | สวมใส่อาวุธ ดาบ โล่ หรือชุดเกราะ |
| `/npc holo add <ข้อความ>` | เพิ่มบรรทัดข้อความลอย Hologram บนหัว |
| `/npc holo remove <บรรทัด>` | ลบบรรทัด Hologram |
| `/npc holo clear` | ล้างข้อความ Hologram ทั้งหมด |
| `/npc cmd add <TYPE> <TRIGGER> <คำสั่ง>` | ใส่คำสั่งในตัว NPC |
| `/npc cmd list` | ดูรายการคำสั่งทั้งหมดในตัว NPC |
| `/npc cmd remove <ลำดับ>` | ลบคำสั่งในตัว NPC ตามลำดับ |
| `/npc tp [id]` | วาร์ปผู้เล่นไปหา NPC |
| `/npc tphere [id]` | ดึง NPC มายังจุดที่ผู้เล่นยืน |
| `/npc look [true\|false]` | สลับเปิด/ปิดระบบหันมองผู้เล่น |
| `/npc reload` | รีโหลดการตั้งค่าทั้งหมด |

## 🔑 Permissions

- `merynpc.admin`: สิทธิ์การใช้งานคำสั่งแอดมินทั้งหมด (ค่าเริ่มต้น: OP)
- `merynpc.interact`: สิทธิ์การคลิกใช้งาน NPC (ค่าเริ่มต้น: ทุกคน)
- `merynpc.bypass.cooldown`: สิทธิ์บายพาสคูลดาวน์คำสั่งของ NPC (ค่าเริ่มต้น: OP)

---

## 📦 ไฟล์และโฟลเดอร์ของปลั๊กอิน

- `plugins/MeryNPC/config.yml`: ตั้งค่าหลัก คูลดาวน์ เสียง และ BungeeCord
- `plugins/MeryNPC/messages.yml`: ตั้งค่าข้อความแจ้งเตือนทั้งหมด รองรับสี HEX
- `plugins/MeryNPC/npcs.yml`: บันทึกข้อมูล NPC ทั้งหมดแบบอัตโนมัติ
