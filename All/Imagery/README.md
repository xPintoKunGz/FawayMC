# ❖ Imagery - Minecraft Plugin (Style 26.3 System)

ปลั๊กอินสำหรับนำรูปภาพจากภายนอกมาแสดงในโลก Minecraft ได้ทันที **โดยผู้เล่นและเซิร์ฟเวอร์ไม่ต้องลง Resource Pack ใดๆ ทั้งสิ้น!** (ใช้ระบบ Vanilla Maps Protocol และ Item Frames ความเร็วสูง)

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

1. **ไม่ต้องลง Resource Pack (Zero Resource Pack Required):**
   - รูปภาพภายนอกจะถูกแปลงเป็น Minecraft Maps โดยตรงจากฝั่งเซิร์ฟเวอร์
   - ผู้เล่นทุกคนที่เข้ามาในเซิร์ฟเวอร์จะมองเห็นรูปภาพได้ทันทีโดยไม่ต้องโหลดแพ็กเกจเสริม
2. **แค่ลากรูปใส่โฟลเดอร์ก็พร้อมใช้งานทันที:**
   - เพียงนำไฟล์รูปภาพมาวางไว้ใน `plugins/Imagery/images/` (รองรับ `.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`)
   - ตั้งชื่อไฟล์ตามใจชอบ เช่น `banner.png`, `logo.jpg` แล้วพิมพ์ `/imagery reload` หรือกดปุ่มรีโหลดใน GUI ได้ทันที
3. **ระบบอัลบั้มและเซ็ตภาพ (Multi-Page Album System):**
   - รวมกลุ่มภาพหลายๆ หน้าเข้าด้วยกันเป็นเซ็ต (เช่น หน้า 1, หน้า 2, หน้า 3, หน้า 4...)
   - **โฟลเดอร์อัตโนมัติ:** เพียงสร้างโฟลเดอร์ใน `plugins/Imagery/images/albums/<ชื่ออัลบั้ม>/` เช่น `albums/rules/` แล้วใส่ `01.png`, `02.png`, `03.png` ระบบจะจัดเป็นอัลบั้มให้ทันที!
   - มี **Demo Album** ตัวอย่าง 3 หน้าติดตั้งมาให้พร้อมทดสอบทันที
4. **คลิกเปลี่ยนหน้าภาพในโลกได้แบบเรียลไทม์ (Interactive Page Flipping):**
   - **คลิกขวาที่รูปในโลก:** เปลี่ยนไปหน้าถัดไปทันที (หน้า 1 > 2 > 3 > 4... วนลูป)
   - **Shift + คลิกขวา:** ย้อนกลับไปหน้าก่อนหน้า
   - มีเสียงเปิดหน้ากระดาษ (`ITEM_BOOK_PAGE_TURN`) และแจ้งเตือนหน้าปัจจุบันใน Action Bar
   - **สไลด์โชว์อัตโนมัติ (Auto Slideshow):** ตั้งค่าให้ภาพหมุนเปลี่ยนหน้าเองทุกๆ 3s, 5s, 10s หรือ 30s ได้
5. **เพิ่มคำสั่งในรูปภาพ (Click Actions & Commands):**
   - เมื่อผู้เล่นคลิกที่รูปภาพ สามารถสั่งให้รันคำสั่งได้ทันที
   - รองรับทั้งคำสั่งผู้เล่น (`Player Command`) เช่น `/spawn`, `/menu`, `/warp shop`
   - รองรับคำสั่งคอนโซล (`Console Command`) สำหรับแจกของหรือเปิดสิทธิ์ เช่น `give %player% diamond 1`
   - รองรับ Placeholders: `%player%`, `%uuid%`, `%world%`, `%x%`, `%y%`, `%z%`, `%page%`, `%max_page%`
6. **ระบบ GUI สไตล์ 26.3 สวยงาม (Style 26.3 Aesthetics):**
   - ออกแบบด้วยโทนสี Gradient Deep Cyan, Neon Mint, Amethyst, Rose Gold
   - **Main Hub GUI (`/imagery`):** ศูนย์ควบคุมหลัก (คลังภาพ, อัลบั้ม, จัดการตำแหน่ง)
   - **Gallery GUI:** ดูภาพเดี่ยวทั้งหมดในโฟลเดอร์
   - **Album Manager GUI:** ดูและวางอัลบั้มภาพ
   - **Command & Slideshow Manager GUI:** ตั้งค่าคำสั่งในภาพและรอบเวลาสไลด์โชว์
   - **Placed Manager GUI:** ตรวจสอบพิกัด `[X, Y, Z]`, ทิศทาง, ระยะห่าง, วาร์ป และยิงลำแสงอนุภาค (Highlight 12s)
   - **Resize Editor GUI:** ปรับขนาดบล็อกสดแบบเรียลไทม์

## 🚀 วิธีการติดตั้ง (Installation)

1. นำไฟล์ **`Imagery.jar`** ไปวางไว้ในโฟลเดอร์ `plugins/` ของเซิร์ฟเวอร์ Minecraft ของคุณ (รองรับ Spigot / Paper / Purpur 1.20+)
2. รีสตาร์ทเซิร์ฟเวอร์
3. โฟลเดอร์ `plugins/Imagery/images/` และ `plugins/Imagery/images/albums/demo_album/` จะถูกสร้างขึ้นให้อัตโนมัติ พร้อมรูปตัวอย่างให้พร้อมทดลองได้ทันที!

## 📖 วิธีการใช้งาน (How to Use)

### 1. วางภาพเดี่ยวหรืออัลบั้มผ่าน GUI:
1. หันหน้ามองไปที่ผนังหรือกำแพงที่ต้องการวางภาพ (ระยะไม่เกิน 6 บล็อก)
2. พิมพ์คำสั่ง `/imagery` หรือ `/imagery gui`
3. เลือก:
   - **คลังรูปภาพเดี่ยว:** เพื่อวางภาพปกติ 1 ภาพ
   - **อัลบั้ม & เซ็ตภาพ:** เพื่อวางเซ็ตภาพหลายหน้า (สามารถคลิกเปลี่ยนหน้าได้)

### 2. การคลิกเปลี่ยนหน้าและรันคำสั่งในเกม:
- **คลิกขวาที่ภาพในโลก:** สลับไปหน้าถัดไป (เช่น หน้า 1 -> หน้า 2 -> หน้า 3) พร้อมรันคำสั่งที่ผูกไว้
- **Shift + คลิกขวาที่ภาพในโลก:** สลับถอยหลังกลับไปหน้าก่อนหน้า
- **ติดตั้งคำสั่งในภาพ:** พิมพ์ `/imagery list` แล้ว Shift + คลิกขวาที่รูป เพื่อเปิดหน้าต่าง **ตั้งค่าคำสั่ง & สไลด์**

## ⌨️ รายการคำสั่งทั้งหมด (Commands)

| คำสั่ง (Command) | คำอธิบาย (Description) |
| :--- | :--- |
| `/imagery` หรือ `/imagery gui` | เปิดเมนูหลักศูนย์ควบคุม Style 26.3 |
| `/imagery album` | เปิดหน้าต่างจัดการอัลบั้มและเซ็ตภาพ |
| `/imagery album place <ชื่ออัลบั้ม> [กว้าง] [สูง]` | วางอัลบั้มลงบนผนังตรงหน้า |
| `/imagery page <รหัสภาพ> <หน้า>` | สลับภาพที่วางอยู่ไปหน้าที่ต้องการ |
| `/imagery cmd add <รหัสภาพ> <player\|console> <คำสั่ง>` | เพิ่มคำสั่งให้รันเมื่อมีคนคลิกภาพ |
| `/imagery cmd list <รหัสภาพ>` | ดูรายการคำสั่งทั้งหมดที่ผูกไว้ในภาพ |
| `/imagery cmd remove <รหัสภาพ> <ลำดับ>` | ลบคำสั่งที่ผูกไว้ออก |
| `/imagery gallery` | เปิดคลังภาพเดี่ยว |
| `/imagery list` | ตรวจสอบพิกัดและจัดการภาพในโลก |
| `/imagery place <ชื่อไฟล์> [กว้าง] [สูง]` | วางภาพเดี่ยวที่ผนังตรงหน้าที่มองอยู่ |
| `/imagery resize <รหัสภาพ> <กว้าง> <สูง>` | ปรับขนาดภาพที่วางไปแล้ว |
| `/imagery tp <รหัสภาพ>` | วาร์ปไปยังตำแหน่งของภาพนั้นๆ |
| `/imagery highlight <รหัสภาพ>` | เปิดลำแสงอนุภาคส่องตำแหน่งรูปภาพ |
| `/imagery delete <รหัสภาพ>` | ลบรูปภาพออกจากโลก |
| `/imagery reload` | รีโหลดโฟลเดอร์ images/ และ albums/ |

*(Aliases: `/img`, `/image`, `/images`)*

## 📂 โครงสร้างโฟลเดอร์ภาพ

```
plugins/Imagery/
├── config.yml                <- ตั้งค่าขนาดสูงสุด, กรอบล่องหน, เวลาลำแสง
├── placed_images.yml         <- บันทึกพิกัดและคำสั่งของภาพที่วางในโลก
├── albums.yml                <- บันทึกอัลบั้มที่สร้าง
└── images/                   <- โฟลเดอร์สำหรับใส่รูปภาพภายนอก
    ├── welcome.png           <- รูปเดี่ยว
    ├── my_banner.jpg         <- รูปเดี่ยว
    └── albums/               <- โฟลเดอร์สำหรับทำอัลบั้มหลายหน้า
        ├── demo_album/       <- อัลบั้มตัวอย่าง (มี 3 หน้า)
        │   ├── page1_intro.png
        │   ├── page2_features.png
        │   └── page3_commands.png
        └── rules/            <- ตัวอย่างอัลบั้มกฎเซิร์ฟเวอร์
            ├── 01_rule.png   <- หน้าที่ 1
            ├── 02_rule.png   <- หน้าที่ 2
            └── 03_rule.png   <- หน้าที่ 3
```
