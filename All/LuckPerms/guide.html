คู่มือการจัดการเครือข่าย BungeeCord & LuckPerms

การแชร์ยศอัตโนมัติข้ามเซิร์ฟเวอร์ (Cross-Server Multi-Sync) แบบไม่ต้องใช้ MySQL

ระบบ: Linux Symlink ชนิดข้อมูล: YAML Storage แม่ข่าย: fawaymc-4AATL

1. ภาพรวมโครงสร้างระบบ (Architecture Overview)

ระบบนี้ใช้เทคนิค Linux Symbolic Link (ทางลัดระดับ OS) ในการเชื่อมต่อ ทำให้ทุกเซิร์ฟเวอร์อ่านและเขียนไฟล์ยศชุดเดียวกัน:

  • แม่ข่ายหลัก (Master): เซิร์ฟเวอร์ BungeeCord (fawaymc-4AATL) เก็บโฟลเดอร์ไฟล์ยศจริงที่ .../plugins/LuckPerms/yaml-storage
  • เซิร์ฟเวอร์ลูกข่าย (Clients): เช่น Lobby, Bedwars, Survival จะมีโฟลเดอร์ yaml-storage ที่เป็น Link ชี้ตรงมาหาแม่ข่าย
  • ข้อดีเด่น: จัดการเป็นไฟล์ .yml เปิดอ่านง่ายเหมือน GroupManager ในอดีต กินแรมน้อย และไม่ต้องเปิดพอร์ต Database ให้เสี่ยงต่อการถูกแฮก

2. สรุปขั้นตอนการเพิ่มเซิร์ฟเวอร์ห้องใหม่ (New Server Setup)

เมื่อคุณสร้างเซิร์ฟเวอร์ใหม่บนโฮสต์ (สมมติชื่อโฟลเดอร์ห้องว่า SERVER_NAME) ให้ทำตาม 4 ขั้นตอน:

ขั้นตอนที่ 1: เตรียมไฟล์ปลั๊กอินใส่ในห้องใหม่

นำไฟล์ปลั๊กอินต่อไปนี้ไปวางในโฟลเดอร์ plugins/ ของห้องใหม่:

  • LuckPerms-Bukkit-5.5.71.jar (ระบบยศ)
  • Vault.jar (บริดจ์เชื่อมระบบยศกับปลั๊กอินอื่น)
  • LPC.jar (แสดงผลยศในช่องแชทอัตโนมัติ)

ขั้นตอนที่ 2: ตั้งค่าระบบ BungeeCord

  • ในห้องใหม่: แก้ไข server.properties ตั้ง online-mode=false และใน spigot.yml ตั้ง bungeecord: true
  • ใน Bungee (fawaymc-4AATL): นำ IP และ Port ของห้องใหม่ไปกรอกใน config.yml ใต้หัวข้อ servers:

ขั้นตอนที่ 3: รันคำสั่งเชื่อมโยงยศใน Terminal (คำสั่งเดียวเสร็จทันที)

เปิดหน้าต่าง SSH Terminal แล้วก๊อปปี้คำสั่งนี้ไปวาง โดยเปลี่ยนแค่ชื่อห้องตรง SERVER="...":

SERVER="ใส่ชื่อโฟลเดอร์ห้องใหม่ตรงนี้" && \ mkdir -p /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/$SERVER/plugins/LuckPerms && \ rm -rf /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/$SERVER/plugins/LuckPerms/yaml-storage && \ ln -s /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/fawaymc-4AATL/plugins/LuckPerms/yaml-storage /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/$SERVER/plugins/LuckPerms/yaml-storage && \ sed -i 's/storage-method:.*/storage-method: yaml/' /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/$SERVER/plugins/LuckPerms/config.yml 2>/dev/null && \ echo "=== เชื่อมโยงสำเร็จเรียบร้อย! ===" && \ ls -ld /var/www/krachabmitr.nahost.in.th/storage/app/minecraft-servers/$SERVER/plugins/LuckPerms/yaml-storage

ขั้นตอนที่ 4: สตาร์ตเซิร์ฟเวอร์ใหม่และตรวจสอบ

  1. สตาร์ตเปิดเซิร์ฟเวอร์ห้องใหม่ขึ้นมา
  2. เข้าเกมแล้วพิมพ์ /lp info ตรวจสอบว่าบรรทัด Storage: Type: ต้องขึ้นเป็น YAML
  3. พิมพ์ /lp listgroups จะพบยศทั้งหมดโผล่มาทันทีโดยไม่ต้องสร้างใหม่

3. สรุปคำสั่งจัดการยศที่ใช้บ่อย (LuckPerms Cheat Sheet)

การทำงาน คำสั่ง ตัวอย่าง
สร้างยศใหม่ /lp creategroup <ยศ> /lp creategroup vip
ตั้งสียศและชื่อในแชท /lp group <ยศ> meta setprefix <wt> "<สี>[<ชื่อ>] &f" /lp group vip meta setprefix 10 "&a[VIP] &f"
ตั้งลำดับความสำคัญยศ /lp group <ยศ> setweight <เลข> /lp group vip setweight 10
ให้สิทธิ์แก่ยศ /lp group <ยศ> permission set <perm> true /lp group vip permission set essentials.fly true
การสืบทอดยศ /lp group <ยศสูง> parent add <ยศต่ำกว่า> /lp group admin parent add vip
ให้ยศผู้เล่น /lp user <ผู้เล่น> parent set <ยศ> /lp user Steve parent set vip
ลดยศผู้เล่นออก /lp user <ผู้เล่น> parent remove <ยศ> /lp user Steve parent remove vip
แต่งยศผ่านหน้าเว็บ /lp editor (เปิดลิงก์บนบราวเซอร์ กดแต่งแล้วกดเซฟ)
สั่งรีโหลดดึงยศล่าสุด /lp reloadnodes (ใช้เมื่อแก้ไขกลุ่มแล้วห้องอื่นยังไม่เห็น)

4. กฎสำคัญและการแก้ไขปัญหา (Troubleshooting)

⚠️ จุดที่ต้องระวัง: ค่า Storage ต้องเป็น YAML เสมอ

หากพิมพ์ /lp info แล้วยังขึ้น Storage: Type: H2 ปลั๊กอินจะไม่ยอมอ่านไฟล์ร่วมกัน ให้แก้ไขใน config.yml ให้เป็น storage-method: yaml แล้วรีสตาร์ตเซิร์ฟเวอร์ห้องนั้น 1 ครั้งเสมอ

💡 ทริคการซิงค์ข้อมูลยศในชีวิตประจำวัน
  • เมื่อให้ยศผู้เล่น: ผู้เล่นย้ายห้องไปห้องไหน ยศจะติดตัวไปด้วยทันทีอัตโนมัติ 100%
  • เมื่อสร้างยศใหม่ หรือแก้สิทธิ์ในยศ: แนะนำให้สร้างผ่าน BungeeCord แล้วในเซิร์ฟเวอร์ย่อยอื่นๆ ให้พิมพ์คำสั่ง /lp reloadnodes 1 ครั้ง เพื่อดึงไฟล์ใหม่เข้าหน่วยความจำ (RAM)
