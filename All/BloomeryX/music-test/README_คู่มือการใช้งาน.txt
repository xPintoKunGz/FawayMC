================================================================================
          🌸 BloomeryX — การลงเพลงด้วยโปรแกรม Note Block Studio (.nbs)
================================================================================

ปลั๊กอิน BloomeryX รองรับการนำไฟล์เพลงจากโปรแกรม Note Block Studio (.nbs)
มาใส่ลงในเซิร์ฟเวอร์โดยตรง และเล่นเป็นเสียงโน้ตในเกม 100% (ไม่ต้องมี Resource Pack!)

【 วิธีนำเพลงจากโปรแกรม Note Block Studio มาลง 】
--------------------------------------------------------------------------------
1. เปิดโปรแกรม Minecraft Note Block Studio (หรือ Open Note Block Studio)
2. สร้างเพลง หรือเปิดไฟล์เพลง (เช่น เพลงโดราเอมอน, เพลงวิบวับ หรือเพลงอนิเมะ/เพลงสากล)
3. กด Save / Export ออกมาเป็นไฟล์นามสกุล `.nbs` เช่น:
   - `doraemon.nbs`
   - `wipwup.nbs`
4. นำไฟล์ `.nbs` เหล่านั้นไปใส่ในโฟลเดอร์:
   `plugins/BloomeryX/songs/`
5. เข้าเกมแล้วพิมพ์คำสั่ง: `/music reload`
6. เมื่อพิมพ์ `/music` หรือ `/music play <ชื่อไฟล์>` เพลง Note Block จะบรรเลงทันที!

================================================================================
       🏷️ ระบบ Nametag เหนือหัว & Tablist เชื่อมต่อ LuckPerms
================================================================================
- เมื่อผู้เล่นหรือเพื่อนมี Rank/ยศ ใน LuckPerms:
  - เหนือหัวตัวละคร (Nametag): จะแสดง Prefix + Nickname/ชื่อ + Suffix
  - เมื่อกดปุ่ม TAB: จะเห็นชื่อของตนเองและเพื่อนทุกคนพร้อม Prefix, Nickname, Suffix สีสวยงาม
  - เชื่อมต่อกับคำสั่ง `/nick <ชื่อ>` รองรับโค้ดสี Hex ทันที!
