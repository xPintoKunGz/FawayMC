# AntiMery Anti-Cheat v26.3 🛡️

ปลั๊กอิน Minecraft ป้องกันโปรแกรมโกง (Anti-Cheat), กันบิน (Anti-Fly), กรองคำหยาบภาษาไทยและภาษาอังกฤษ (Anti-Swear) แบบครบวงจรสำหรับเซิร์ฟเวอร์ Spigot / Paper / Purpur

---

## ✨ ฟีเจอร์หลัก (Features)

### 1. ระบบกันบินและแก้บัคการโดนเตะผิดพลาด (Smart Anti-Fly & Fix False Kicks)
- **ไม่เตะคนที่ได้รับอนุญาตจากคำสั่ง**: หากผู้เล่นได้รับอนุญาตให้บินจากคำสั่งเซิร์ฟเวอร์ (เช่น `/fly`, Essentials, CMI, TempFly) หรือได้รับสิทธิ์จากแอดมิน **จะไม่โดนเตะเด็ดขาด!**
- **ไม่เตะคนได้รับผลจากยาหรือเอฟเฟกต์ (Potion Effects)**: ป้องกันและละเว้นอัตโนมัติเมื่อผู้เล่นได้รับผลของยา เช่น ยาบิน (Levitation), ยาลอยตัวช้า (Slow Falling), ยาวิ่งไว (Speed), ยากระโดดสูง (Jump Boost), Dolphin's Grace, Conduit Power
- **ไม่เตะคนถูกวาร์ปหรือได้รับแรงกระแทก**: ให้สิทธิ์ภูมิคุ้มกันชั่วคราวเมื่อผู้เล่นวาร์ป (`/tp`, `/spawn`, `/warp`) หรือโดนแรงกระแทกจากระเบิด, ลม (Wind Charge) หรือกระโดดแทรมโพลีน
- **เตะหรือแบนทันทีเมื่อบินโดยไม่มีเหตุผล**: หากผู้เล่นไม่มีบล็อกรองรับ, ไม่มียา, ไม่มีเอฟเฟกต์, ไม่มีคำสั่งอนุญาต แล้วลอยตัวหรือบินขึ้นในอากาศ **ระบบจะสั่งเตะออกทันที (หรือแบนทันทีหากตั้งค่าไว้ โดยมีค่าเริ่มต้นคือเตะออก)**!

### 2. ระบบป้องกันการเข้าแทรกไอดี (Anti-Hijack / Duplicate Login Bypass) 🔒
- ออกแบบมาเพื่อป้องกันเซิร์ฟเวอร์ไอดีเถื่อน (Cracked / Offline-mode) หรือไฮบริด
- **ป้องกันการเข้าแทรก (Session Hijacking)**: เมื่อมีผู้เล่น (เช่น เจ้าของบัญชี หรือ แอดมิน) กำลังออนไลน์อยู่ในเซิร์ฟเวอร์ หากมีใครอื่นใช้ตัวเกมเถื่อนพิมพ์ชื่อเดียวกันเพื่อเข้าแทรกเพื่อเตะคนเก่าออก **ระบบจะปฏิเสธการเชื่อมต่อและบล็อคไม่ให้เข้าเซิร์ฟเวอร์ทันที!**
- ผู้เล่นที่ออนไลน์อยู่จะปลอดภัย ไม่หลุดออกจากเกม และไม่โดนขโมยสิทธิ์หรือไอเทม

### 3. ระบบตรวจจับการแฮคและโกงรอบด้าน (All-in-One Movement & Combat Checks)
- **Speed Check**: ป้องกันการวิ่งเร็วผิดธรรมชาติ (มีระบบคำนวณเอฟเฟกต์ Potion Speed และบล็อกน้ำแข็งอัตโนมัติ)
- **NoFall Check**: ตรวจจับการหลอกข้อมูลบนพื้นเพื่อไม่ให้เสียเลือดจากการตกจากที่สูง
- **Jesus / WaterWalk**: ตรวจจับการเดินบนผิวน้ำหรือลาวาโดยไม่จม (ยกเว้นรองเท้า Frost Walker หรือยานพาหนะ)
- **HighJump / Step**: ตรวจจับการกระโดดสูงหรือก้าวบล็อกอัตโนมัติ **รองรับปลั๊กอินอื่นในเซิร์ฟเวอร์เต็มรูปแบบ** (เช่น แท่นดีด/จัมป์แพด, แทรมโพลีน, ดับเบิ้ลจัมป์, หรือสกิลไอเทมต่างๆ ที่ส่งแรงดีดจากระบบเซิร์ฟเวอร์ จะไม่ถูกเตะ) **แต่ถ้ากระโดดสูงลอยขึ้นไปโดยไม่มีต้นเหตุจากเซิร์ฟเวอร์ จะเตะออกทันที (หรือแบนหากตั้งค่าไว้)!**
- **FastClimb**: ตรวจจับการปีนบันไดหรือเถาวัลย์ด้วยความเร็วสูง
- **KillAura**: ตรวจจับการโจมตีรอบทิศทาง โจมตีนอกระยะสายตา หรือการโจมตีหลายเป้าหมายพร้อมกันใน 1 tick
- **Reach Check**: ตรวจจับการโจมตีจากระยะไกลเกินกว่ากำหนด (เกิน 4.2 บล็อก)
- **AutoClicker**: ตรวจจับจำนวนคลิกต่อวินาที (CPS) เกินกว่าที่กำหนด (ค่าเริ่มต้น 20 CPS)
- **Criticals Check**: ตรวจจับการทำคริติคอลปลอมขณะยืนบนพื้นหรือติดในใยแมงมุม
- **FastBreak / Nuker**: ตรวจจับการขุดบล็อกรวดเร็วผิดปกติ หรือขุดบล็อกที่ไม่สามารถขุดได้ (Bedrock, Barrier)
- **FastPlace**: ตรวจจับการวางบล็อกรัวเกินกำหนด
- **FastUse**: ตรวจจับการกินอาหารหรือยิงธนูเร็วผิดปกติ

### 4. ระบบตรวจจับไคลเอนต์และแฮค (Client Brand & Hack Client Detector) 🔍
- **ตรวจจับไคลเอนต์ยอดนิยมสำหรับ PvP**:
  - `Lunar Client`, `LabyMod`, `Badlion Client`, `Feather Client`
  - มีข้อความแจ้งเตือน Staff เมื่อผู้เล่นเชื่อมต่อด้วย PvP Client
- **ตรวจจับไคลเอนต์ทั่วไป (Vanilla / Mod Loaders)**:
  - `Vanilla Minecraft`, `OptiFine`, `Fabric`, `Forge`, `Quilt`, `NeoForge`, `PojavLauncher`
- **ตรวจจับและแบน/เตะแฮคไคลเอนต์อัตโนมัติ (Auto-Block Famous Hack Clients)**:
  - ดักจับแฮคยอดนิยม เช่น **Wurst, Meteor, LiquidBounce, Aristois, Sigma, Impact, Inertia, BleachHack, RusherHack, Future, Vape, FDP Client, ThunderHack, Mathax, Augustus, Rise, Novoline, Astolfo, Flux**
  - เมื่อพบผู้เล่นเชื่อมต่อด้วยแฮคไคลเอนต์ จะสั่ง **เตะออกทันที (หรือแบนทันที)** พร้อมแจ้งเตือนทีมงานในเซิร์ฟเวอร์
- **คำสั่งเช็คไคลเอนต์**:
  - `/antimery client <player>` : ใช้ตรวจสอบว่าผู้เล่นคนนั้นใช้ Client ตัวไหนเล่นอยู่ (เช่น Lunar Client, LabyMod, Vanilla, หรือ Hack)

### 5. ระบบกรองคำหยาบคายภาษาไทย อังกฤษ และคาราโอเกะ (Thai, English & Karaoke Swear Filter)
- กรองคำหยาบภาษาไทยยอดนิยมครบถ้วน (ควย, เหี้ย, สัส, เชี่ย, มึง, กู, เย็ด, ส้นตีน, ฯลฯ)
- กรองคำหยาบคาราโอเกะ / ทับศัพท์ภาษาอังกฤษยอดนิยม เช่น **`kuy`**, `kuay`, `khuy`, `yed`, `hee`, `sus`, `sat`, `sud`, `kwai`, `meung`, ฯลฯ
- กรองคำหยาบภาษาอังกฤษสากล (fuck, shit, bitch, ass, dick, cunt, ฯลฯ)
- **ระบบเซ็นเซอร์เฉพาะคำหยาบในประโยค (Censor-in-Place)**:
  - หากผู้เล่นพิมพ์ข้อความ เช่น `kuyพีค` ระบบจะแปลงเป็น **`***พีค`** อัตโนมัติ โดยคงคำอื่นๆ ไว้ไม่ให้หาย
  - หากพิมพ์ `ควยพีค` จะถูกแปลงเป็น **`***พีค`**
  - ดักจับการเคาะวรรคหลบหลีก เช่น `k u y พีค` หรือ `ค ว ย พีค` จะถูกเปลี่ยนเป็น **`*** พีค`**
  - ป้องกันคำถูกต้อง (Whitelist) ไม่ให้ถูกเซ็นเซอร์ผิดพลาด เช่น `class`, `grass`, `กินข้าว`, `ครับ`
- **ตรวจสอบทุกคนไม่มียกเว้น (`filter-everyone: true`)**:
  - ตรวจจับทั้งแอดมิน, OP, คนธรรมดา, และผู้เล่นในโหมด Creative ทุกคนโดยไม่ข้ามสิทธิ์ เพื่อป้องกันการหลุดกรอง
- **รองรับทั้ง Spigot และ Paper (`AsyncPlayerChatEvent` + `AsyncChatEvent`)**:
  - รองรับระบบแชทสมัยใหม่ของ Paper 1.19+ / 1.20+ / 1.21+ / 26.x รวมถึงคำสั่งแชทอย่าง `/me`, `/msg`, `/tell`, `/w`
- รูปแบบการทำงานในคอนฟิก (`action`):
  - `CENSOR` : แปลงเฉพาะคำหยาบเป็น `***` (ค่าเริ่มต้นตามที่ต้องการ)
  - `BLOCK` : บล็อกไม่ให้ส่งข้อความทั้งหมด
  - `NOTHING` : ปล่อยผ่าน แต่ยังคิดคะแนนความผิด
- มีระบบนับจำนวนครั้งการทำผิด (VL) หากพิมพ์คำหยาบซ้ำๆ เกินกำหนด (เช่น 3 ครั้ง) ระบบจะสั่งเตะออก หรือแบนตามที่กำหนดไว้ในคอนฟิก

### 6. ระบบการลงโทษที่ปรับแต่งได้อิสระ (Configurable Punishments)
สามารถตั้งค่าแยกตามแต่ละระบบ หรือใช้ค่ากลาง (Default) ได้:
- **`KICK` (ค่าเริ่มต้น)** : เตะผู้เล่นออกจากเซิร์ฟเวอร์ทันที
- **`WARN`** : ส่งข้อความตักเตือนผู้เล่น และเล่นเสียงแจ้งเตือน
- **`BAN`** : แบนผู้เล่นออกจากเซิร์ฟเวอร์
- **`COMMAND`** : รันคำสั่ง Console ที่กำหนด เช่น `tempban %player% 1d [AntiMery] ตรวจพบการโกง`
- **`NOTIFY_ONLY`** : แจ้งเตือนเฉพาะทีมงาน (Staff) ที่มีสิทธิ์เท่านั้น

## 🚀 วิธีการติดตั้ง (Installation)

1. นำไฟล์ `AntiMery-26.3.jar` จากโฟลเดอร์ `target/` ไปวางในโฟลเดอร์ `plugins/` ของเซิร์ฟเวอร์ Minecraft
2. รีสตาร์ทเซิร์ฟเวอร์ หรือใช้คำสั่ง `/reload confirm`
3. ไฟล์คอนฟิกจะถูกสร้างขึ้นอัตโนมัติที่ `plugins/AntiMery/config.yml`

## ⚙️ สิทธิ์การใช้งาน (Permissions)

| Permission | รายละเอียด | ค่าเริ่มต้น |
|---|---|---|
| `antimery.admin` | สิทธิ์ใช้งานคำสั่งผู้ดูแลระบบ `/antimery` | OP |
| `antimery.alerts` | สิทธิ์รับข้อความแจ้งเตือนเมื่อมีคนโกงหรือพิมพ์คำหยาบ | OP |
| `antimery.bypass` | ข้ามการตรวจจับทุกระบบ | OP |
| `antimery.bypass.fly` | อนุญาตให้บินได้โดยไม่ถูกตรวจจับ | OP |
| `antimery.bypass.movement` | ข้ามการตรวจจับความเร็วและการเดิน | OP |
| `antimery.bypass.combat` | ข้ามการตรวจจับการต่อสู้ (KillAura, Reach, CPS) | OP |
| `antimery.bypass.chat` | ข้ามการตรวจจับคำหยาบในแชท | OP |
| `antimery.bypass.world` | ข้ามการตรวจจับการขุด/วางบล็อก | OP |

## 💻 คำสั่ง (Commands)

- `/antimery help` : ดูคู่มือการใช้งานคำสั่ง
- `/antimery reload` : รีโหลดการตั้งค่า `config.yml` และคำศัพท์โดยไม่ต้องรีสตาร์ทเซิร์ฟเวอร์
- `/antimery stats <player>` : ดูประวัติคะแนนความผิด (VL) ของผู้เล่น
- `/antimery reset <player>` : ล้างค่าคะแนนความผิดของผู้เล่น
- `/antimery warn <player> [เหตุผล]` : ส่งข้อความตักเตือนผู้เล่น
- `/antimery kick <player> [เหตุผล]` : เตะผู้เล่นออกจากเซิร์ฟเวอร์
- `/antimery ban <player> [เหตุผล]` : แบนผู้เล่นออกจากเซิร์ฟเวอร์
