# ✦ Bedwars Next-Generation Plugin (MC 26.3 / 1.20+ / 1.21+)

ปลั๊กอิน **Bedwars** ยุคใหม่ พัฒนาขึ้นมาแทนที่ `BedwarsRel` รุ่นเก่า เพื่อรองรับ Minecraft 26.3 และ Minecraft เวอร์ชั่นใหม่ (1.20 - 1.21+) ทำงานลื่นไหล ไม่พึ่งพา NMS เก่า มีระบบเมนูที่สวยงาม ทันสมัย และเชื่อมต่อกับระบบเสริมอย่างสมบูรณ์แบบ

---

## 🌟 ฟีเจอร์และการปรับปรุงระบบทั้งหมด

### 1. 🤖 ระบบ AI Pro Bedwars Bot อัจฉริยะ (เรียนรู้สไตล์ผู้เล่นระดับสูง)
- **Ninja Bridging กดย่อต่อบล็อกเร็วข้ามเหว (`ต่อบล็อกกดย่อได้โหดๆ`):** บอทตรวจจับขอบเกาะและเหว เมื่ออยู่ตรงขอบจะกดย่อ (`Shift / Sneaking`) ถือบล็อกขนแกะสีทีมแล้วต่อบล็อกข้ามเหวไปกลางอย่างแม่นยำ พร้อมปลดย่อวิ่งเร็วเมื่ออยู่บนบล็อกแข็ง
- **ระบบคลุมเตียงและกันเตียงมือโปร (`คลุมเตียงเป็น + กันเตียงโหดๆ`):** เมื่อเริ่มเกม บอทจะนำทรัพยากร (End Stone / ไม้ / ขนแกะ) ไปต่อบล็อกคลุมรอบเตียงทั้ง 6 ทิศทางและด้านบนจนมิดชิด และหากมีศัตรูบุกเข้ามาใกล้เตียง (< 16 บล็อก) บอทจะรีบวิ่งกลับมาป้องกันเตียงทันที
- **ถือดาบมือหลัก + ถือโล่มือรอง (`ใช้โล่ถือดาบ`):** มือรองถือ Shield ตลอดเวลา เมื่อถูกโจมตีมีโอกาส 45% ยกโล่บล็อกดาเมจได้ 85% สะท้อนแรงผลักกลับพร้อมเสียงและประกายไฟ
- **แลกธนูและยิงสไนเปอร์ระยะไกล (`แลกธนูยิงธนูได้ด้วย`):** ซื้อ Bow และ Arrow จากร้านค้า เมื่อศัตรูอยู่ในระยะ 7 - 24 บล็อก บอทจะเล็งยิงธนูพร้อมคำนวณวิถีโค้งสมจริง
- **บินข้ามเหวและเซฟตัวเองไม่ให้ตกเหว (`ใช้ปีกบินเองได้ / Clutch`):** บอทสามารถพุ่งข้ามเหวด้วย Elytra / Wind Burst Leap และหากพลาดตกเหวต่ำกว่าเกาะ จะใช้ไข่มุก Ender Pearl Clutch วาร์ปกลับขึ้นมาบนเกาะได้อย่างน่าทึ่ง
- **เจาะเกราะเตียงศัตรู:** เมื่อบุกเตียงศัตรูที่มีบล็อกคลุม บอทจะขุดบล็อกที่คลุมเตียงออกก่อนแล้วจึงตีเตียงแตก
- **จำลองสกินและชื่อผู้เล่น 100%:** ใส่หัวสกินของผู้เล่นจริง (`Player Skull Head`), ชุดเกราะสีทีม, ป้ายชื่อสีทีม + ชื่อผู้เล่น **ไม่มีคำว่า `[Bot]`** ทั้งบนหัว ในแชท หรือข้อความตาย
- **คงชื่อใน Tab & Scoreboard:** ชื่อของผู้เล่นยังคงแสดงอยู่ในทีมบน Tab และ Scoreboard ระหว่างแมตช์
- **เก็บแร่ Diamond และ Emerald:** เดินไปเก็บเพชรและมรกตที่แท่นเกิด
- **แลกของและอัปเกรดทีม:** นำเพชรไปอัปเกรด Sharpness และ Protection ให้ทีม, นำมรกต/ทอง/เหล็กไปอัปเกรดเกราะ ดาบ ซื้อธนู และซื้อ Golden Apple กินฟื้นฟูเลือด
- **สู้กับศัตรูทั้งคนและบอท (`สู้กันเองได้`):** มีระบบตรวจจับศัตรูรอบตัว โจมตีด้วยดาบ กระโดดคริติคอล และผลัก Knockback
- **พิมพ์แชทคุยกันเองได้:** ส่งข้อความแชทเป็นระยะในชื่อผู้เล่น เช่น "rush mid", "watch their bed", "careful", "bed covered", "got emeralds", "gg"
- **เงื่อนไขหลุดกันหมดทั้งสองทีม:** หากผู้เล่นมนุษย์ทุกคนหลุดออกจากเกมพร้อมกัน แมตช์จะตัดสินจบเกมทันที (Draw / แพ้ทั้งคู่)

### 2. 🎬 ปรับปรุงระบบ Replay และแก้ไขบัคการทับแมพ 100% (แสดงบอทเป็นตัวคนสกินผู้เล่น)
- **เห็นตัวบอทใน Replay เป็นตัวคนสกินแท้ 100%:** แก้ไขบัคที่ Replay เดิมไม่บันทึกบอท ตอนนี้ Replay บันทึกบอททุกคน (ทั้งบอทฝึกซ้อม Practice Bots และบอทแทนคนหลุด Rejoin Bots) และแสดงผลใน Replay ด้วยโมเดลผู้เล่น 3D พร้อมสกินผู้เล่นจริง เลเยอร์เสื้อผ้า หมวก เกราะสีทีม อาวุธ และการเหวี่ยงแขนโจมตี
- **ตัดขาดไม่ยุ่งกับแมพหลัก (100% Isolated):** ใช้ Packet-based ServerPlayer NPC จำลองสกินผู้เล่นแบบ Hypixel และ MeryNPC โดยไม่มีตัวตน entity จริงในเซิร์ฟเวอร์
- **ออกจาก Replay สะอาด 100%:** เมื่อกด Slot 8 (Barrier) หรือกดออกจากรีเพลย์:
  - ล้าง Action Bar ทันที
  - ลบตัวละคร Packet NPCs ทั้งหมด
  - รีเซ็ตบล็อกที่พรีวิวกลับเป็นสภาพแมพจริง
  - ปลดการซ่อนผู้เล่น ทำให้เห็นกันตามปกติ
  - คืนสถานะและไอเท็มล็อบบี้ สามารถกดเพชร (Diamond Start) เริ่มเกมได้ทันที ไม่มีค้าง
- **สามารถลบ Replay ได้:** คลิกขวาที่แผนที่ในเมนู `/bw replay` เพื่อลบไฟล์ หรือพิมพ์ `/bw replay delete <id>`

### 3. 🎯 โหมดฝึกซ้อมเล่นกับบอทในทุกแมพ (Bot Practice Mode)
- **เลือกจำนวนทีมที่จะเปิดบอทได้ตามใจชอบ:**
  - เข้าผ่านการ **คลิกขวาที่แมพในเมนู `/bw menu`** หรือคลิกไอเทม **Blaze Rod (Bot Practice Setup)** ในห้องรอ หรือพิมพ์ `/bw practice [arena] [จำนวนทีม]`
  - สามารถเลือกพรีเซ็ตด่วน:
    - 🗡️ **1 Enemy Team:** ซ้อมดวล 1v1 สำหรับฝึก Speedrun และต่อสะพาน
    - 🗡️ **2 Enemy Teams:** ซ้อมรับมือศึก 2 ด้าน
    - 💎 **3 Enemy Teams:** ซ้อมตะลุมบอน 3 ทีม
    - ⚔️ **ALL Enemy Teams:** เติมบอทเต็มทุกทีมของแมพนั้นๆ
  - หรือคลิกที่บล็อกขนแกะสีทีมเพื่อเปิด/ปิดบอทรายทีมได้อย่างอิสระ
- **บอทฝึกซ้อมเล่นสมจริง:** บอทจะต่อสะพานไปกลาง เก่งฉลาด เดินเก็บเพชร/มรกต อัปเกรดเกราะ ดาบ แลกของ กินแอปเปิ้ลทอง ตีเตียงศัตรู และสู้กันเอง
- **คิดสถิติและจบเกมสมบูรณ์:** เมื่อผู้เล่นทำลายเตียงและกำจัดบอทหมดทุกทีม จะประกาศชัยชนะ (Victory) และบันทึก Replay ให้ชมย้อนหลังได้ทันที!

### 3. 📂 หมวดหมู่แยกโหมดในเมนูเลือกห้อง (`/bw menu`)
- เพิ่มแถบเลือกหมวดหมู่แถวบนสุด:
  - `ALL` (Compass) - ทุกโหมด
  - `SOLO` (Iron Sword) - โหมด Solo (1 คนต่อทีม / 8x1)
  - `DOUBLES` (Golden Sword) - โหมด Doubles (2 คนต่อทีม / 8x2)
  - `3v3v3v3` (Diamond Sword) - โหมด 3v3v3v3 (3 คนต่อทีม / 4x3)
  - `4v4v4v4` (Netherite Sword) - โหมด 4v4v4v4 (4 คนต่อทีม / 4x4)
- แสดงจำนวนทีม x ผู้เล่น เช่น `4 Teams x 4 (4x4)`
- คลิกสลับหมวดหมู่ได้ทันที พร้อมแสงเรืองแสง (Enchanted Glow) บนหมวดหมู่ที่เลือก

### 4. 👨‍🌾 Villager ในแมพไม่มีอาชีพ (No Profession)
- ชาวบ้านร้านค้า (Item Shop) และอัปเกรด (Team Upgrades) ในแมพใช้ Vanilla `Villager` พร้อมตั้ง `setProfession(Profession.NONE)` เป็นชุดชาวบ้านธรรมดา ไม่มีหมวกหรือผ้ากันเปื้อนอาชีพ และตัดปัญหาข้อความกวนใจจาก MeryNPC ออก 100%

### 5. 🛒 แก้ไขบัค Shop ไอเท็มทับกัน และบัคที่กดซื้อไม่ได้ 100%
- แยกแถวหมวดหมู่ชัดเจน: หมวดหมู่ทั้งหมดถูกย้ายไปอยู่แถวที่ 2 (Row 1, Slots 9-16) เท่านั้น
- ช่องไอเทมแยกขาดเด็ดขาด: ไอเทมสินค้าทั้งหมดจะอยู่ตั้งแต่ช่อง 18 เป็นต้นไป (Rows 2-5)
- ไม่ส่งข้อความแชทตอนซื้อของ เพื่อไม่ให้รกหน้าจอ

### 6. 🏷️ ชื่อใน Tab และ NameTag บนหัวเป็นสีตามทีม (Team Colors in Tab)
- ผู้เล่นทุกคนจะมีสีชื่อในแถบกด Tab และบนหัวเป็นสีตามทีม เช่น สีแดง, สีน้ำเงิน, สีเขียว, สีเหลือง ฯลฯ

### 7. 🍗 กินอาหารแล้วเลือดเพิ่มทันที (Food Eating Heals HP)
- เมื่อรับประทานอาหารชนิดใดก็ตาม ฟื้นฟูเลือดทันที +4 HP (2 หัวใจ) พร้อมเอฟเฟกต์หัวใจลอยรอบตัว

### 8. ⚔️ ดาบมีได้แค่อันเดียว + ซื้อดาบใหม่ทับดาบเดิมทันที
- ผู้เล่นจะมีดาบในช่องเก็บของได้เพียง 1 เล่มเท่านั้น เมื่อซื้อดาบใหม่จะทับเล่มเก่าทันที

### 9. 🗡️ ของเริ่มต้นไม่เอนชานต์ (Vanilla Clean Start)
- ดาบไม้และชุดเกราะหนังเริ่มต้นไม่มีเอนชานต์

### 10. 🏆 ตัดสินผลชนะทันทีเมื่อเตียงแตกและศัตรูตายหมด (Instant Win)

### 11. 👁️ ระบบ Spectator + นาฬิกาวาร์ปไปส่องผู้เล่น (Spectator Teleporter Clock)
- ไอเทมนาฬิกาคลิกเพื่อเปิด GUI หัวผู้เล่นและวาร์ปไปส่องได้ทันที

### 12. 💖 ตอนเกิดใหม่เลือดและอาหารรีเซ็ตเต็ม 100%

### 13. 🤖 Iron Golem ไม่ตีเพื่อนร่วมทีม + ป้องกันเพื่อนตีโกเลม

### 14. 💧 น้ำ/ลาวา และของเหลวที่วาง หายหมด 100% เมื่อจบเกม

### 15. ⏳ การเกิดแร่ในฐานสูตรสมบูรณ์ 100%
- เหล็กเกิดทีละ 1 ก้อน ทุก 1 วินาที, ทองเกิดทีละ 1 ก้อน ทุก 4 วินาที ปรับแต่งได้ใน `config.yml`

### 16. 🛡️ ป้องกันการเสกของและการให้ OP ขณะอยู่ในเกม (Anti-Cheat Console & Command Shield)
- บล็อกคำสั่ง `op`, `deop`, `give`, `item` จากคอนโซลและแอดมินขณะที่ผู้เล่นกำลังแข่งอยู่ในเกม

## 📌 คำสั่งหลัก (Main Commands)

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/bw menu` | เปิดเมนูเลือกห้องเล่น Bedwars พร้อมตัวกรองแยกโหมด (Solo, Doubles, 3v3, 4v4) |
| `/bw quick` | สุ่มเข้าห้องที่พร้อมเล่นเร็วที่สุด |
| `/bw leave` | ออกจากเกมหรือห้องรอ |
| `/bw rejoin` | กลับเข้าแมตช์ที่หลุดเชื่อมต่อ (เข้าแทนที่ Bot) |
| `/bw replay` | เปิดดูประวัติการแข่งขันและเข้าชม Replay ย้อนหลัง |
| `/bw replay delete <id>` | ลบไฟล์รีเพลย์แมตช์ที่ต้องการ |
| `/bw practice [arena]` | โหมดฝึกซ้อมกับบอท (เลือกจำนวนทีมที่เปิดบอทได้) |
| `/bw setspawn` | กำหนดจุดเกิดเริ่มต้นของเซิร์ฟเวอร์เมื่อจบเกม |
| `/bw setmainlobby` | กำหนดจุดวาร์ป Main Lobby รวม |
| `/bw maps` | เปิดเมนูจัดการอารีน่า (Admin) |
| `/bw setup <arena>` | เปิด Setup Wizard ตั้งค่าห้อง (Admin) |
| `/bw reload` | รีโหลดคอนฟิกของปลั๊กอิน |
